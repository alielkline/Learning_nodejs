# Learning Node.js 🚀

A personal playground where I learn Node.js by building. This repo collects small apps, experiments, and notes on core Node.js concepts as I implement and develop them.

> **Status:** 🌱 Work in progress. New examples are added as I learn.

---

## 🎯 Goals

- Understand how Node.js works under the hood (event loop, modules, streams, etc.)
- Practice by building small, focused projects
- Keep a reference of working code and notes for future me

---

## ⚙️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/alielkline/learning-nodejs.git
```
